# Modern Reader

A typography-first, minimalist web reader and client-side PDF viewer calibrated for longform reading on MacBook screens (with responsive layout for mobile and desktop).

## Features

- **Optimal Reading Measure**: Centered column (710px) providing balanced margins and 65–75 characters per line to eliminate visual fatigue on 13" MacBook screens.
- **Macintosh Typographic Stacks**: Editorial Serif (Charter / Iowan Old Style), Modern Sans (SF Pro / Inter), and Classical Press.
- **5 Reading Themes**: Warm Paper (Substack / iBooks sepia), Clean White, Vintage Sepia, Night Slate, and OLED Black.
- **Client-Side PDF & File Reader**: Drag and drop any `.pdf`, `.txt`, or `.md` file, or paste text to read in this clean layout.
- **100% Client-Side Privacy**: All documents and PDFs dropped into the reader are processed entirely in browser memory. No data is ever transmitted to a server.
- **Distraction-Free Zen Mode**: Toggle with `Z` or top button.
- **Keyboard Shortcuts**:
  - `T` — Cycle color themes
  - `Z` — Toggle Zen mode
  - `Esc` — Close settings and modals
